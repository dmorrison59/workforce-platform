# Workforce Platform — Agent Instructions

Modular workforce-operations SaaS for small businesses (~5–50 employees):
scheduling, employee self-service, coverage, time tracking, labor intelligence,
crews/jobs, and optional GPS field-clock verification. Multi-tenant, built on
Next.js + Supabase/PostgreSQL with Row Level Security as the enforcement layer.

Current milestone: see the "Current Milestone" section of README.md and
BUILD_ROADMAP.md — do not assume a gate is complete without checking there.

## Commands

```
pnpm typecheck
pnpm lint
pnpm test            # vitest unit suite
pnpm test:db         # RLS/database tests — requires local Supabase (pnpm db:start)
pnpm test:e2e --workers=1
pnpm build
pnpm check           # typecheck + lint + test + build
```

Run the relevant subset after every change and report actual pass/fail —
never claim a test passed without running it (see CODEX_RULES.md #20).
